# Как поднять личного Jira-бота

Эта инструкция для коллег без опыта программирования. Главная идея: вы скачиваете проект, открываете его в Codex или Claude Code, вставляете prompt, а дальше общаетесь с AI обычным языком. Большую часть технических действий сделает AI.

Бот умеет:
- создать одну или сразу несколько задач одним сообщением c указанием эпика, спринта, исполнителя, Story Points, описание задачи;
- изменить Story Points у существующей задачи по названию или ключу.

Если эпик, спринт или исполнитель не указаны, бот подставляет значения по умолчанию, которые задавались при создании бота, или может найти похожие варианты и предложить их.

> Пример создания одной задачи:
> - Заведи тикет Title с оценкой 5 на Иванова с описанием Description
> - Создай задачу: Title. Эпик Epic Name. Спринт Sprint Name. Estimate 2
>
> Пример создания сразу нескольких задач:
> - Заведи задачи Title1 с оценкой 2. задачу Title2 с оценкой 5. задачу Title3 с оценкой 0.2
>
> Примеры изменения оценки у заведённой задачи:
> - Измени в задаче Title оценку на 0.5
> - Измени ABC-12345 Estimate 3
> - Измени оценку Title на 0.1
>
> Если вы хотите, чтобы бот понимал другие команды, просто попросите его об этом.

Важно: не отправляйте токены, пароли и содержимое `.env` людям в чат. Если AI просит секрет, попросите его объяснить, в какую строку `.env` вставить значение, и вставьте руками.

## Минимальные шаги

1-3 шаги – это основной сценарий. Скорее всего, дальше первых 3х шагов идти не придется.

### 1. Скачать проект

1. Откройте ссылку на репозиторий.
2. Нажмите `Code`.
3. Нажмите `Download ZIP`.
4. Распакуйте архив.
5. Положите папку проекта в удобное место.

В папке проекта должны быть файлы:

```text
README.md
pyproject.toml
src
scripts
```

### 2. Открыть проект в Codex или Claude Code

1. Откройте Codex/Claude Code.
2. Выберите папку проекта.

Если не знаете, как открыть папку проекта в Codex или Claude Code, спросите прямо:

```text
Как мне открыть папку проекта в Codex или Claude Code на Mac?
```

### 3. Вставить prompt

Скопируйте и вставьте этот prompt в Codex или Claude Code:

```text
Помоги мне поднять личного Telegram-бота для создания задач в Jira.

Я не программист. Веди меня короткими шагами и объясняй простыми словами.

Работай в текущей папке проекта.

Важно:
- не выводи в чат содержимое .env, токены, пароли и API keys;
- если нужно вставить секрет, скажи мне, какую строку открыть в .env, но сам секрет не проси писать в чат;
- если .env еще нет, создай его из .env.example;
- помоги мне заполнить .env по шагам;
- объясни, где взять TELEGRAM_BOT_TOKEN, JIRA_BASE_URL, JIRA_PROJECT_KEY, JIRA_BOARD_ID, customfield_*, дефолтный эпик, дефолтный спринт и дефолтного исполнителя;
- после заполнения .env сам выполни проверки проекта;
- если проверка упала, объясни простыми словами, что исправить;
- когда все готово, сам запусти бота как сервис;
- проверь, что бот работает;
- в конце дай мне 3 сообщения, которыми проверить бота в Telegram.
```

После этого просто отвечайте AI на вопросы. Можно писать обычным языком:

```text
Я не понял, где взять board id. Объясни проще.
```

```text
Открой мне .env.
```

```text
Проверь, правильно ли я заполнил настройки, но не показывай токены.
```

### 4. Открыть `.env`

`.env` — это файл с личными настройками. Туда вставляются токены, Jira-адрес, проект и дефолты.

Сначала попросите AI:

```text
Открой мне .env в обычном редакторе.
```

Если AI попросил открыть `.env` вручную, сначала перейдите в папку проекта:

1. Откройте Terminal.
2. Напишите `cd `, обязательно с пробелом после `cd`.
3. Перетащите папку проекта в окно Terminal. Путь к папке подставится сам.
4. Нажмите Enter.

Должно получиться примерно так:

```bash
cd /Users/yourname/Documents/jira_assistent
```

После этого выполните команду открытия `.env`:

```bash
open -a TextEdit .env
```

Если пользуетесь VS Code:

```bash
code .env
```

Все остальные технические команды пусть выполняет Codex или Claude Code.

### 5. Проверить бота в Telegram

Когда AI скажет, что бот запущен, откройте Telegram и напишите своему боту:

```text
/start
```

Потом отправьте тест:

```text
Заведи тикет Тестовая задача с оценкой 1 с описанием Проверка создания задачи.
```

На подтверждении нажмите `Нет`, если не хотите создавать тестовую задачу.

## Здесь заканчиваются минимальные шаги

Дальше — справочная информация. Ее не обязательно читать сразу. Если что-то непонятно, проще спросить Codex или Claude Code человеческим языком.

## Что вставлять в `.env` и где это взять

Ниже перечислены основные поля. Не нужно запоминать все сразу: открывайте этот раздел, когда AI попросит конкретное значение.

### TELEGRAM_BOT_TOKEN

Это токен вашего личного Telegram-бота.

Где взять:

1. Откройте Telegram.
2. Найдите `@BotFather`.
3. Напишите:

```text
/newbot
```

4. BotFather попросит имя бота. Например:

```text
My Jira Assistant
```

5. Потом попросит username. Он должен заканчиваться на `bot`, например:

```text
my_jira_assistant_bot
```

6. BotFather выдаст token.

Куда вставить:

```env
TELEGRAM_BOT_TOKEN=сюда_вставить_токен_из_BotFather
```

### JIRA_BASE_URL

Это адрес Jira без хвоста `/browse/...`.

Пример: если ссылка на задачу выглядит так:

```text
https://jira.company.local/browse/ABC-123
```

то в `.env` нужно:

```env
JIRA_BASE_URL=https://jira.company.local
```

### JIRA_PROJECT_KEY

Это буквенный ключ проекта.

Пример:

```text
ABC-123
```

`ABC` — это project key.

Куда вставить:

```env
JIRA_PROJECT_KEY=ABC
```

### JIRA_USERNAME

Ваш логин в Jira.

```env
JIRA_USERNAME=ваш_логин
```

### JIRA_API_TOKEN

Это токен или пароль для Jira.

Где взять:

- если Jira поддерживает Personal Access Token, создайте токен в профиле Jira;
- если Jira старая, может использоваться обычный пароль от Jira;
- если не знаете, спросите Jira-админа или коллегу: “Что использовать для Jira API: Personal Access Token или пароль?”

Куда вставить:

```env
JIRA_API_TOKEN=ваш_токен_или_пароль
```

### JIRA_AUTH_MODE

Если используете Personal Access Token:

```env
JIRA_AUTH_MODE=bearer
```

Если используете логин и пароль:

```env
JIRA_AUTH_MODE=basic
```

### JIRA_BOARD_ID

Это id Jira-доски, нужен для поиска активного спринта.

Где взять:

1. Откройте вашу Jira-доску.
2. Посмотрите адресную строку браузера.
3. Найдите кусок вида:

```text
rapidView=123
```

4. Число `123` — это board id.

Куда вставить:

```env
JIRA_BOARD_ID=123
```

Если в ссылке нет `rapidView`, спросите AI:

```text
В ссылке на доску нет rapidView. Как мне найти JIRA_BOARD_ID?
```

## Как найти customfield_*

Это самая непонятная часть, но ее обычно нужно сделать один раз.

В `.env` есть такие строки:

```env
JIRA_EPIC_LINK_FIELD=customfield_TODO
JIRA_EPIC_NAME_FIELD=customfield_TODO
JIRA_SPRINT_FIELD=customfield_TODO
JIRA_TASK_TYPE_FIELD=customfield_TODO
JIRA_ESTIMATE_FIELD=customfield_TODO
```

### Вариант 1. Просто попросить Codex или Claude

Это самый простой путь. Подключите VPN и напишите AI:

```text
Подключен VPN. Найди customfield_* для моего Jira-проекта. Не выводи секреты из .env.
```

AI сам выполнит проверку проекта и подскажет, какие значения вставить в `.env`.

Если AI спросит данные, отвечайте обычным языком. Например:

```text
Project key у меня ABC, board id 123. Нужно найти поля Epic Link, Sprint, Story Points и Тип задачи.
```

### Вариант 2. Вручную через страницу создания задачи в Jira

1. Подключите VPN.
2. Откройте Jira в браузере.
3. Откройте создание задачи в нужном проекте.
4. Откройте DevTools:

```text
Command + Option + I
```

5. Перейдите во вкладку `Network`.
6. Создайте тестовую задачу или просто измените поля на форме.
7. В Network найдите запрос, связанный с созданием или метаданными задачи. Часто он называется примерно:

```text
issue
createmeta
field
```

8. Откройте найденный запрос.
9. Нажмите `Command + F` и ищите названия полей:

```text
Epic Link
Epic Name
Sprint
Story Points
Тип задачи
Estimate
```

10. Рядом с названием поля обычно будет id вида:

```text
customfield_12345
```

Эти значения нужно вставить в `.env`.

Если сложно, скопируйте не секретный кусок ответа из DevTools и спросите AI:

```text
Я нашел в DevTools такой кусок ответа Jira. Помоги определить customfield для Epic Link, Sprint, Story Points и Тип задачи. Секретов тут нет.
```

### Что означает каждое поле

```env
JIRA_EPIC_LINK_FIELD=customfield_...
```

Поле, через которое задача связывается с эпиком.

```env
JIRA_EPIC_NAME_FIELD=customfield_...
```

Поле названия эпика.

```env
JIRA_SPRINT_FIELD=customfield_...
```

Поле спринта.

```env
JIRA_TASK_TYPE_FIELD=customfield_...
```

Обязательное поле “Тип задачи”, если оно есть в вашей Jira.

```env
JIRA_ESTIMATE_FIELD=customfield_...
```

Поле Story Points или Estimate.

## Значения по умолчанию

Если вы не укажете эпик, спринт или исполнителя в сообщении, бот возьмет дефолты из `.env`.

### Дефолтный эпик

Откройте нужный эпик в Jira.

Если ссылка такая:

```text
https://jira.company.local/browse/ABC-456
```

то:

```env
JIRA_DEFAULT_EPIC_KEY=ABC-456
```

Название эпика скопируйте из Jira:

```env
JIRA_DEFAULT_EPIC_NAME="Название эпика"
```

### Дефолтный спринт

Если спринты называются так:

```text
[ABC:TEAM] 18.05-29.05
[ABC:TEAM] 01.06-12.06
```

можно указать общий префикс:

```env
JIRA_DEFAULT_SPRINT_QUERY="[ABC:TEAM]"
```

Бот будет искать активный спринт с этим префиксом.

### Дефолтный исполнитель

Нужно заполнить:

```env
JIRA_DEFAULT_ASSIGNEE_KEY=user_key
JIRA_DEFAULT_ASSIGNEE_NAME=Фамилия Имя Отчество
JIRA_DEFAULT_ASSIGNEE_EMAIL=user@company.ru
```

Если не знаете `user_key`, попросите AI:

```text
Найди в Jira пользователя по ФИО и подскажи, что вставить в JIRA_DEFAULT_ASSIGNEE_*.
```

## Примеры сообщений боту

Создать одну задачу:

```text
Заведи тикет Title с оценкой 5 на Иванова с описанием Description
```

```text
Создай задачу: Title. Эпик Epic Name. Спринт Sprint Name. Estimate 2
```

Создать несколько задач:

```text
Заведи задачи Title1 с оценкой 2. задачу Title2 с оценкой 5. задачу Title3 с оценкой 0.2
```

Изменить Story Points:

```text
Измени в задаче Title оценку на 0.5
```

```text
Измени ABC-123 Estimate 3
```

```text
Измени оценку Title на 0.1
```

Description:

```text
Заведи тикет Title с описанием Создать окно подтверждения. Ссылка www.example.com.
```

## Если хотите свои команды

Просто общайтесь с Codex или Claude Code человеческим языком.

Примеры:

```text
Сделай так, чтобы бот понимал команду "поставь оценку задаче Title 3".
```

```text
Добавь в /help новый пример сообщения.
```

```text
Сделай так, чтобы бот при создании задачи спрашивал подтверждение другим текстом.
```

Любые доработки допускаются. Просите AI сразу проверять изменения:

```text
Прогони тесты, перезапусти сервис и коротко напиши, что изменилось.
```
